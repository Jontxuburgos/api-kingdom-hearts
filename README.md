> **Read in other languages:**  

An open-source RESTful API built to deliver structured data about the worlds across the *Kingdom Hearts* video game series.

⚠️ **Note:** This project is currently **Work in Progress (WIP)**. Features and data schema may change as new content is added.

---

## 🌟 Features

- **Multi-language Support:** Retrieve content in English (default), Spanish, and Japanese using query parameters.
- **RESTful Endpoints:** Clean URL structure for querying all worlds or specific entries by ID.
- **Visual Interface:** Includes a lightweight web dashboard to explore the worlds interactively.
